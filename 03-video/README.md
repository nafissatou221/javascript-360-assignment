//LocalStorage and Event Delegation
The goal of this project was to create a shopping list where we can add items, check them off when they are done, and keep them saved even when we reload or reopen the page.
One important thing I learnt was how to use `localStorage` to save the items. Usually,when we reload a page, the data we added can disappear. But when we use localStorage the items stay saved even after reloading the page. I also learnt how `JSON.stringify()` converts an array into a string so it can be stored in localStorage, and how `JSON.parse()` converts the saved string back into Javascript data. They work together because we need to convert it back when retrievieng it.
I also learnt that `this.reset` is for clearing the form so we can be abble to add another value in it. Another lesson was the difference between `push()` and `innerHTML`. push() adds a new item into an array, while innerHTML displays the items on the webpage.
Finally, I learnt about `event delegation`, which allow a parent element to handle clicks on its child elements. Instead of adding a separate click event listener to every checkbox, we add one listener to the parent<ul>.This makes the code simpler because the same listener can handle clicks on all the checkboxes, including newly added one. We use `e.target` to know which element was clicked and matches ('input') to check if it was a checkbox. If it wasn't, return stops the function. The data-index attribute gives each item a number so we know which item was clicked, and `dataset.index`  lets javascrip get that number. Then, `items[index].done=!items[index].done` changes the item's status from checked to unchecked or vice versus. So the updated list is saved in the localStorage, and the webpage is undated to show the changes.
