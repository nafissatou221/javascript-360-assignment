// CSS + JS Clock
The goal of this project was to build a clock using HTML for the creation of the elements, CSS making them look like a clock, and JavaScript helping to calculate where the hands should point.
I learnt from this project that 'FlexBox' is a CSS layout system used to arrange and align elements.For example one of its properties is "display: flex"  which is for the activation of the Flexbox while "align-items:center" helps align elements along the cross axis. I also discovered box-shadow, which adds shadows around or inside an element to create effect.I learnt how to use CSS properties such as "transform-origin" to define the pivot point of the clock hands,"rotate()" to turn them to the correct position,and "translateY()" to move an element vertically.I also learned how to use CSS transitions to animate the clock hands and how "cubic-bezier()" controls the movement, creating a bouncing effect that makes the hands look like they are ticking. Finally, I learned how to use javascript's "Date()" object to retrieve the current time, calculate the rotation angles for each hand,and use "setInterval()" to update the clock every second.
