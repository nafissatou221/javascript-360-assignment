// Flex Panel Image Gallery
The goal of this project is to create five panels with background images. When we click one of them, it expands and becomes bigger than the others, while the text slides into view.
In this project, I learned more about the use of FlexBox and how we can use it in different ways. For example, `display: flex` on the .panels container makes the five panels appear next to each other horizontally. Then, we use `flex-direction: column` inside each panel to arrange the text vertically. We also use Flexbox to center the text inside each area. I also learned about `box-sizing: inherit`, with `*, *:before, *:after` to apply the same `box-sizing` rule to all elements, including their pseudo-elements. I also learnt the use og `forEach` which is a permitting us to go through each panel and add click event to it, instead of adding an event listener to each panel separately. Another new thing for me was the `transitionend` event, which runs when a CSS transition finishes, and `e.propertyName` which tells us which css propoerty has finished transitionning. We use these to add the open-active class when a panel finishes expanding, making the text slide into view.
